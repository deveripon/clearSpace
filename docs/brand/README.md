# Clearspace brand

| File | Use |
| --- | --- |
| `clearspace-logo.svg` | Main logo (mark + wordmark) on light backgrounds |
| `clearspace-logo-white.svg` | Main logo on dark backgrounds |
| `clearspace-mark.svg` | The mark on its own: avatars, small spaces |
| `clearspace-wordmark.svg` | Wordmark on its own |
| `clearspace-symbol.svg` | One-colour symbol with no tile (uses `currentColor`) |
| `app-icon.svg` | macOS app icon source (1024 grid); `build/icon.png` is rendered from it |
| `favicon.svg` | Favicon, with a heavier stroke so it holds at 16 px |

**Colours:** teal `#1b9aa6` → `#0a5964` (tile gradient), sparkle mint `#a8efe6`, ink `#0e1a1d`.
**Type:** the wordmark is Inter Display SemiBold, converted to outlines, tracked −2.2%.
**Clear space:** keep at least half the mark's height empty around the logo. Don't recolour, stretch or add effects to the mark.
